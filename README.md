## 这本书是什么

《国产FDE修炼之道》是一本面向**想转型/入行FDE的中国软件工程师**的实战手册。

FDE（Forward Deployed Engineer，前线部署工程师）岗位招聘量在2025→2026年间暴涨729%，国内字节跳动、腾讯云、智谱等大厂相继开出35K-80K/月的薪资。但现有中文资料普遍偏硅谷视角——国内FDE面临的私有化部署、数据合规、国企客户等挑战，几乎没有系统梳理。

本书填补这个空白。
